# `src/utils`

Funções puras e auxiliares sem dependência de React: formatação de data e
hora, ordenação, validações locais de formulário.

Regras:

- Funções puras e testáveis isoladamente. Nada de chamada de rede nem de
  acesso a estado global.
- Regra de negócio de verdade (distribuição do plano de estudos) vive no
  backend, não aqui.

Vazio nesta etapa.
